# 4TRADERS

موقع عربي لأخبار الفوركس (React + Vite).

## نشر على GitHub Pages

```bash
npm install
npm run deploy
```

هذا يبني المشروع ويدفعه إلى فرع `gh-pages`.

ثم في GitHub: **Settings → Pages**
- Source: **Deploy from a branch**
- Branch: `gh-pages` / `/ (root)`

الرابط: https://mehdiazzam.github.io/4Traders/

## محلياً

```bash
npm run dev
```
